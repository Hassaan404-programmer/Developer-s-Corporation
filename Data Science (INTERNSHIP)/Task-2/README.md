# Task 2: Credit Risk Prediction

This project is part of a Data Science Internship, focusing on credit risk prediction using loan data.

## Dataset

The dataset used is `loan-train.csv`, which contains training data for loan approval prediction.

## Files

- `Task_2.ipynb`: Jupyter notebook containing the data analysis, preprocessing, visualization, and model training for credit risk prediction.
- `loan-train.csv`: The training dataset.

## Requirements

To run this notebook, you need:

- Python 3.x
- Jupyter Notebook
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn (and others as used in the notebook)

Install dependencies using pip:

```
pip install pandas numpy matplotlib seaborn scikit-learn
```

## Usage

1. Open the `Task_2.ipynb` file in Jupyter Notebook or Jupyter Lab.
2. Run the cells in order to perform data exploration, preprocessing, model training, and evaluation.

## Description

The notebook covers:

- Data loading and initial exploration
- Data cleaning and preprocessing
- Exploratory data analysis (EDA) with visualizations
- Feature engineering
- Model training (likely classification models for loan approval)
- Model evaluation

## Troubleshooting

- Ensure the path to `loan-train.csv` is correct in the notebook.
- If running in Google Colab, the path might be different; adjust accordingly.
- Make sure all required libraries are installed.
