## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab

### Recommended Setup

1. Create a virtual environment:
   ```bash
   python -m venv venv
   ```
2. Activate the environment:
   - Windows:
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - macOS/Linux:
     ```bash
     source venv/bin/activate
     ```
3. Install required packages (if any are specified in the notebook):
   ```bash
   pip install -r requirements.txt
   ```

> If no `requirements.txt` file exists, open the notebook and install packages as needed.

## Usage

Open the notebook with Jupyter:

```bash
jupyter notebook Task_1.ipynb
```

or with JupyterLab:

```bash
jupyter lab Task_1.ipynb
```
