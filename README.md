# Data Science Internship Tasks

This repository contains the first three internship tasks completed as part of a Data Science program. Each task is stored in its own folder with a Jupyter Notebook and supporting dataset files.

## Tasks Included

### Task 1 - Iris Dataset
- Folder: `Task-1`
- Notebook: `Task_1.ipynb`
- Description: Exploratory analysis and modeling using the Iris dataset.
- Notes: The task includes analysis, visualization, and any conclusions generated during the internship assignment.

### Task 2 - Credit Risk Prediction
- Folder: `Task-2`
- Notebook: `Task_2.ipynb`
- Dataset: `loan-train.csv`
- Description: Credit risk analysis and classification modeling to predict loan approval or borrower risk.

### Task 3 - Customer Churn Prediction
- Folder: `Task-3`
- Notebook: `customer_churn_prediction.ipynb`
- Dataset: `Churn_Modelling.csv`
- Description: Predicting customer churn using machine learning and analyzing important churn drivers.

## How to Run

1. Install Python 3.x.
2. Install Jupyter Notebook or JupyterLab.
3. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
4. Install required packages. Common libraries used across tasks include:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```
5. Open the notebook for the task you want to run:
   ```bash
   jupyter notebook Task-1\Task_1.ipynb
   ```

## Notes

- Each task folder contains a README with more details for that specific assignment.
- If a `requirements.txt` file is present in a task folder, install packages from it before running the notebook.
- Update dataset paths in the notebooks if you move files or run them from a different working directory.
